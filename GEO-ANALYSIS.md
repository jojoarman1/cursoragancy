> Поэтому все находки ниже — это SEO-основы, применённые к AI Overviews, AI Mode, ChatGPT и Perplexity.

## 3. Доступ AI-краулеров

`/robots.txt`:

```
User-Agent: *
Allow: /
Sitemap: http://localhost:3000/sitemap.xml
```

- GPTBot, OAI-SearchBot, ClaudeBot, PerplexityBot, Google-Extended — **разрешены** (правило `*`).
- Отдельных блокировок нет. Если не хочется отдавать контент в обучение моделей, можно закрыть только обучающих ботов (`CCBot`, `Google-Extended`, `anthropic-ai`), оставив поисковых.
- Пользовательские фетчеры (ChatGPT-User, Google-Agent) robots.txt не читают по определению — это нормально.

**Критично перед запуском:** `Sitemap`, `canonical`, `og:url` и JSON-LD сейчас указывают на `http://localhost:3000`, потому что не задан `NEXT_PUBLIC_SITE_URL`. На продакшене его нужно выставить, иначе поисковики получат неверные адреса.

## 4. llms.txt

`/llms.txt` отсутствует (404). Google Search его игнорирует и явно пишет, что он не влияет на видимость; для других AI-систем эффект не подтверждён. **Приоритет низкий.** Если захочется, шаблон:

```
# Cursor Agency
> Digital-агентство: проектируем и разрабатываем сайты, веб-сервисы и 3D-интерфейсы.

## Страницы
- [Главная](https://example.com/): кто мы и как связаться

## Контакты
- hello@cursor.agency
```

## 5. Упоминания бренда

Не проверить: название `Cursor Agency` — заглушка (`TODO` в `src/config/site.ts`), упоминаний в Wikipedia, Reddit, YouTube, LinkedIn пока нет.

**Важный риск для выбора названия:** «Cursor» — это известный AI-редактор кода (Anysphere). AI-движки опираются на сущности, и бренд «Cursor Agency» будет смешиваться с ним: по запросу «Cursor» ответы уйдут к редактору, а упоминания агентства могут приписываться не той компании. Если название ещё не окончательное, лучше выбрать различимое; если окончательное — обязательно связать бренд с его площадками через `sameAs` (см. п. 9).

## 6. Цитируемость по абзацам

Абзацев в 134–167 слов (оптимум для цитирования) — **0**. Всё, что видит краулер из осмысленного:

> Cursor Agency. Digital-агентство: проектируем и разрабатываем сайты, веб-сервисы и 3D-интерфейсы.

Этого хватает, чтобы страница нашлась по названию, но не чтобы её процитировали в ответе на запрос вроде «кто делает сайты с 3D», «стоимость разработки сайта агентством» и т.п.

## 7. Проверка SSR (что видно без JavaScript)

Next.js отдаёт HTML на сервере — это хорошо, AI-краулеры JS не выполняют. Видимый текст в HTML (127 «слов»):

```
Cursor Agency Digital-агентство: проектируем и разрабатываем сайты, веб-сервисы и 3D-интерфейсы
2026 ( 0 1 2 3 … 99 100 ) To: Cursor Agency Привет, меня зовут [Enter]
hello@cursor.agency Отправить Спасибо, ! Скоро свяжемся!
```

Проблемы:
- **Счётчик прелоадера** (`0 … 100`) — 101 «слово» мусора, больше, чем весь полезный текст. Может попасть в сниппет.
- **Тексты чата** («Привет, меня зовут», «Спасибо, ! Скоро свяжемся!») — служебные строки интерфейса, тоже кандидаты в сниппет.
- `h1` и описание скрыты (`sr-only`). Для лого-страницы это допустимо (текст совпадает с тем, что изображено), но основной контент в идеале должен быть виден.

## 8. Топ-5 изменений с наибольшим эффектом

1. **Добавить реальный контент на главную** (или отдельные страницы): услуги, 3–5 кейсов с результатами в цифрах, процесс работы, ориентир по срокам/ценам, FAQ. Это единственное, что сдвинет цитируемость с нуля. По Google — уникальный опыт из первых рук, а не общие советы.
2. **Выставить `NEXT_PUBLIC_SITE_URL`** на продакшене, чтобы sitemap, canonical, OG и JSON-LD указывали на настоящий домен.
3. **Убрать служебный текст из сниппетов:** повесить `data-nosnippet` на прелоадер и панель чата (Google поддерживает атрибут на `div`/`section`/`span`). Небольшая правка кода.
4. **Решить с названием бренда** (риск смешения с Cursor, п. 5) и сразу завести страницы бренда (LinkedIn, Telegram/YouTube, Behance/Dribbble), связав их через `sameAs`.
5. **Честная дата в sitemap:** сейчас `lastModified: new Date()` меняется при каждой сборке. Google просит не имитировать свежесть; лучше ставить дату реального изменения контента.

## 9. Рекомендации по разметке

Сейчас: `Organization` (name, url, logo, description) и `WebSite`. Добавить в `Organization`:

```json
{
  "@type": "Organization",
  "email": "hello@cursor.agency",
  "sameAs": ["https://www.linkedin.com/company/…", "https://t.me/…", "https://www.behance.net/…"],
  "knowsAbout": ["веб-разработка", "3D-интерфейсы", "дизайн сайтов"],
  "areaServed": "RU",
  "contactPoint": { "@type": "ContactPoint", "email": "hello@cursor.agency", "contactType": "sales" }
}
```

Когда появятся страницы: `Service` на страницы услуг, `CreativeWork`/`Article` на кейсы, `Person` для команды. `FAQPage`-разметку для коммерческого сайта Google показывает ограниченно, но сам блок FAQ в тексте полезен. Разметка — не рычаг сама по себе: Google просит не вкладываться в неё специально ради AI.

## 10. Что переписать в контенте

Переписывать пока нечего — контента нет. Когда он появится, писать так, чтобы абзацы можно было вырвать из контекста:

- Под каждым заголовком-вопросом («Сколько стоит сайт с 3D?», «Сколько длится разработка?») — первым предложением прямой ответ с цифрой, дальше пояснение.
- В кейсах — конкретика: задача, что сделали, результат в цифрах, срок.
- Самое важное — в верхней трети страницы (~44% AI-цитат берутся оттуда).
- Подпись и дата обновления у кейсов и статей.

## Прочее, замечено попутно

- `user-scalable=no` в viewport (запрет зума) — Lighthouse отмечает это как проблему доступности, а дерево доступности читают AI-агенты. На ранжирование напрямую не влияет.
